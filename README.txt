TOOLMELA REVIEWS INSTALLABLE WEB APP

Upload ALL files to the same folder/root on GitHub Pages:
- reviews.html
- manifest.json
- service-worker.js
- icon-192.png
- icon-512.png

Then replace API_URL in reviews.html with your Google Apps Script Web App URL.

On a supported mobile browser, the page can show an "Install ToolMela Reviews App"
button. This installs it as a PWA on the phone. It is not an APK file.

For a true Android APK, this web app must be packaged with an Android wrapper/TWA
or built as a native Android app.
